# Start Here On The New Mac

This repo is your AI/ML learning home base.

Clone it on the new MacBook Pro:

```bash
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/howdymary/frontier-lab-sprint.git
cd frontier-lab-sprint
```

Then follow:

1. [New MacBook AI/ML Setup](docs/new-macbook-ai-ml-setup.md)
2. [Two-Month Lesson Plan](docs/lesson-plan.md)
3. [Neural Networks and Spiking Neural Networks Track](docs/neural-networks-and-snn.md)
4. [Hiring Memo Template](docs/hiring-memo-template.md)

## Quick Setup

After installing Xcode command-line tools, Homebrew, and `uv`, run:

```bash
./scripts/bootstrap_project.sh
```

That will install this repo's Python environment and run the smoke tests.

## What This Computer Is For

Use the new Mac as a focused AI/ML machine:

- Learn neural networks from first principles.
- Train small models locally.
- Build the JAX transformer and scaling-law project.
- Study spiking neural networks and hardware-aware ML.
- Prototype with PyTorch, MLX, and JAX.
- Keep research notes, code, experiments, and hiring artifacts in one place.
